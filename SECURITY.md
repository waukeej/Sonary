# Security

Sonary is an early development release, not a production-ready platform.

Do not publish vulnerability details, working exploits, cookies, passwords, private files, or keys in public Issues. A dedicated confidential security reporting channel will be added later. Until then, request a private means of communication from the maintainer without disclosing technical details in a public discussion.

Do not use real user data when reproducing an issue. Do not publish `.env`, database dumps, or the contents of `instance/`.
